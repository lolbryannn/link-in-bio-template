# Link in Bio: free template

A link-in-bio page that's yours: no ads, no monthly fee, no "made with…" banner from someone else.
**One HTML file.** Edit a few lines and upload it.

**Live demo:** https://lolbryannn.github.io/link-in-bio-template/?demo

## 🇮🇩 Cara pakai

1. **Unduh** ZIP-nya (tombol hijau **Code → Download ZIP**), lalu ekstrak.
2. Buka `index.html` pakai Notepad / VS Code. Cari tulisan **`EDIT DI SINI`**.
3. Ganti nama, bio, foto, dan link-linkmu. Simpan.
4. Klik dua kali `index.html` untuk melihat hasilnya di browser.
5. **Online-kan gratis:** buka [app.netlify.com/drop](https://app.netlify.com/drop), lalu seret folder ini ke sana. Selesai, kamu dapat link sendiri.
6. Tempel link itu di bio Instagram/TikTok-mu.

**Foto profil:** taruh fotomu di folder yang sama (misal `foto.jpg`), lalu isi `avatar: "foto.jpg"`.

**Tema:** isi `theme` dengan `midnight`, `paper`, `neon`, `peach`, atau `ocean`. Mau warna sendiri? Isi `accent: "#ff3d81"`.

**Tombol WhatsApp dengan pesan otomatis:**
`https://wa.me/628xxxxxxxxxx?text=Halo%2C%20saya%20mau%20pesan`
(nomor pakai 62, tanpa 0 di depan; spasi di pesan ditulis `%20`)

## 🇬🇧 How to use

1. **Download** the ZIP (green **Code → Download ZIP** button) and extract it.
2. Open `index.html` in Notepad / VS Code and look for **`EDIT DI SINI / EDIT HERE`**.
3. Change your name, bio, photo and links. Save.
4. Double-click `index.html` to preview it in your browser.
5. **Put it online for free:** go to [app.netlify.com/drop](https://app.netlify.com/drop) and drag this folder onto the page. You get your own link.
6. Paste that link into your Instagram/TikTok bio.

## Link options

```js
{ title: "Order on WhatsApp",       // button text (required)
  url: "https://wa.me/62…",         // where it goes (required)
  sub: "Replies 9am–9pm",           // small line under the title
  highlight: true,                  // coloured, stands out
  badge: "NEW",                     // little label in the corner
  section: "Shop",                  // heading above this button
  icon: "shop",                     // force an icon (otherwise detected from the URL)
  image: "product.jpg" }            // thumbnail instead of an icon
```

Icons: `instagram` `tiktok` `youtube` `whatsapp` `x` `facebook` `github` `shop` `email` `music` `gift` `calendar` `map` `download` `link`.
Instagram, TikTok, YouTube, WhatsApp, X, Facebook, GitHub, Spotify, Shopee/Tokopedia/Lazada, Google Maps and `mailto:` links get the right icon automatically.

## What's included

- 5 themes plus your own accent colour
- Auto icons for social and shop links
- Highlighted button, badges, section headings, thumbnails
- Share button (opens the phone's share sheet, or copies the link)
- Fast: one file, no libraries, nothing to install
- Mobile-first, works on notched phones, respects "reduce motion"
